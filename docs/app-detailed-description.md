# KJV 리더노트 앱 상세 설명

> 작성 기준: 2026-07-12 · 앱 버전 0.4.0 · 현재 웹 및 Expo 네이티브 앱 구현 기준

## 1. 앱 소개

**KJV 리더노트**는 KJV 성경을 꾸준히 읽고, 읽은 위치와 마음에 남은 구절을 한곳에 기록할 수 있도록 만든 개인 성경 통독·공부 앱입니다. 단순히 성경 본문을 보여주는 데 그치지 않고, 마지막으로 읽은 위치 복원, 통독 진척도 관리, 구절 강조, 장·절 메모, 인용 구절 보관, 본문 검색, 음성 읽기 기능을 하나의 흐름으로 연결합니다.

사용자는 회원가입 없이 바로 성경 읽기를 시작할 수 있습니다. 비회원 기록은 현재 기기에 저장되며, 이메일 계정으로 로그인하면 읽기 기록과 공부 데이터를 서버에 저장해 계정 기준으로 이어갈 수 있습니다. 비회원으로 먼저 사용한 기기 데이터도 로그인 후 계정으로 가져올 수 있습니다.

KJV 리더노트가 해결하려는 핵심 문제는 세 가지입니다.

- 어디까지 읽었는지 잊지 않고 다음 읽기를 자연스럽게 이어가는 것
- 중요한 말씀과 묵상 내용을 읽는 자리에서 바로 기록하는 것
- 설교, 글쓰기, 묵상, 전도와 콘텐츠 제작에 다시 사용할 구절을 쉽게 찾는 것

## 2. 이런 사용자에게 적합합니다

- KJV 성경을 매일 또는 정기적으로 통독하려는 사용자
- 전체·구약·신약·권별 통독 진척도를 확인하고 싶은 사용자
- 중요한 구절을 목적별 색상으로 표시하고 다시 찾아보고 싶은 사용자
- 장이나 구절별로 묵상, 관찰, 적용점을 기록하는 사용자
- 설교, 글쓰기, SNS, 영상 제작 등에 인용할 말씀을 주제별로 모으는 사용자
- 이동 중이거나 화면을 오래 보기 어려울 때 성경을 음성으로 듣고 싶은 사용자
- 영어 KJV 본문과 제공 가능한 한국어 번역을 오가며 읽거나 검색하고 싶은 사용자

## 3. 주요 기능

### 3.1 로그인 없이 시작하는 성경 읽기

앱을 처음 실행한 사용자는 계정을 만들지 않아도 비회원 리더로 진입할 수 있습니다. 성경 읽기, 통독 기록, 강조, 노트, 인용 구절, 설정 등의 데이터는 기기의 로컬 저장소에 보관됩니다. 계정 동기화가 필요해졌을 때 로그인 또는 회원가입을 선택할 수 있으므로, 가입 절차가 읽기 시작을 방해하지 않습니다.

### 3.2 성경 66권 리더

구약과 신약, 성경 권, 장을 선택해 절 단위로 본문을 읽을 수 있습니다. 이전 장과 다음 장 이동, 장 선택, 현재 읽는 절 추적 기능을 제공하며 영어 KJV와 승인·공개된 한국어 본문이 있는 경우 `EN`과 `KR` 표시를 전환할 수 있습니다.

읽기 화면에서는 다음 작업을 바로 실행할 수 있습니다.

- 현재 장 읽음 완료 또는 읽음 취소
- 영어 KJV와 한국어 본문 전환
- 장 전체 음성 읽기
- 장 노트 작성
- 오늘의 통독 분량으로 이동
- 여러 절을 범위로 선택해 복사, 인용 저장 또는 음성 읽기

### 3.3 마지막 위치 자동 저장과 이어 읽기

현재 읽고 있는 성경 권, 장, 절, 스크롤 위치와 마지막 읽은 시간이 저장됩니다. 앱을 다시 열면 홈의 **이어 읽기** 카드에서 마지막 위치를 확인하고 해당 장과 절 근처로 바로 돌아갈 수 있습니다. 로그인 사용자는 이 기록을 계정 데이터로 저장하며, 서버 연결에 문제가 생기면 기기에 저장된 캐시를 이용해 기록을 보호합니다.

### 3.4 통독 진척도와 통독 플랜

읽은 장을 완료 처리하면 전체 성경, 구약, 신약의 통독률에 즉시 반영됩니다. 홈에서 전체 통독률, 오늘 읽은 장 수, 구약·신약 진행 상황을 확인할 수 있으며, 권별 진척도도 살펴볼 수 있습니다.

목표 기간에 따라 다음 통독 플랜을 시작할 수 있습니다.

- **1년 통독**: 하루 약 3~4장
- **6개월 통독**: 하루 약 6~7장
- **90일 통독**: 하루 약 13~14장
- **신약 30일**: 하루 약 8~9장

앱은 시작일과 선택한 플랜을 기준으로 오늘 읽을 장을 계산합니다. 오늘 분량 열기, 오늘 완료, 플랜 다시 시작, 플랜 제거를 지원하며 다음에 읽지 않은 장으로 이동할 수 있습니다.

### 3.5 목적별 구절 강조

중요한 구절을 선택하고 다음 다섯 가지 의미로 색상을 구분해 강조할 수 있습니다.

- 노란색: 중요
- 파란색: 묵상
- 초록색: 약속
- 빨간색: 경고
- 보라색: 예언

강조한 구절에는 짧은 메모를 남길 수 있습니다. 강조 보관 화면에서는 색상과 성경 권으로 구절을 필터링하고, 원래 본문 위치로 다시 이동하거나 구절을 복사하고 강조를 해제할 수 있습니다.

### 3.6 장 노트와 구절 노트

한 장 전체에 대한 묵상과 특정 구절에 대한 생각을 나누어 기록할 수 있습니다. `묵상`, `관찰`, `적용점`과 같은 내용을 자유롭게 작성하고 수정하거나 삭제할 수 있습니다. 홈의 공부 영역에서는 최근 노트를 확인하고 해당 장이나 절로 다시 이동할 수 있습니다.

### 3.7 인용 구절 보관함

설교, 묵상, 글쓰기, 전도, SNS와 영상 제작 등에 다시 사용할 구절을 별도 보관함에 저장할 수 있습니다. 한 구절뿐 아니라 연속된 여러 구절도 범위로 선택해 저장할 수 있습니다.

각 인용 항목에는 다음 정보를 추가할 수 있습니다.

- 기억하기 쉬운 인용 제목
- 사용 목적이나 문맥을 적는 메모
- 주제별 태그
- 하나 이상의 인용 목록

새 목록을 만들거나 기존 목록을 삭제할 수 있고, 제목·본문·태그로 목록 안을 검색할 수 있습니다. 최근 저장순, 성경 순서, 자주 사용순으로 정렬할 수 있으며 개별 구절 또는 목록 전체를 성경 위치와 함께 복사할 수 있습니다.

### 3.8 한국어·영어 성경 본문 검색

한국어, KJV 영어 또는 전체 언어 범위에서 키워드를 검색할 수 있습니다. 검색 범위는 전체 성경, 구약, 신약 또는 특정 성경 권으로 좁힐 수 있으며, 결과를 성경 순서 또는 관련도순으로 정렬할 수 있습니다.

검색 결과에는 일치한 표현이 강조되어 표시됩니다. 결과를 선택하면 해당 장을 열고 목표 구절을 선택한 상태로 보여주므로, 검색에서 읽기와 기록으로 자연스럽게 이어집니다.

### 3.9 기기 음성을 이용한 TTS

기기에 설치된 음성을 사용해 현재 장, 선택한 한 구절, 선택한 여러 구절 또는 오늘의 통독 분량을 들을 수 있습니다. 재생, 일시정지, 다시 시작, 정지 기능을 제공하고 읽는 속도와 음성을 설정할 수 있습니다.

한국어 본문은 한국어 음성으로, KJV 영어 본문은 영어 음성으로 읽도록 구성되어 있습니다. 사용할 수 있는 음성의 종류와 발음 품질, 일시정지 동작은 기기 운영체제와 설치된 TTS 엔진에 따라 달라질 수 있습니다.

### 3.10 읽기 환경 설정

사용자의 읽기 환경에 맞게 다음 항목을 조정할 수 있습니다.

- 글자 크기
- 줄 간격
- 밝은 테마와 어두운 테마
- 기본 본문 언어
- 영어·한국어 병렬 본문 표시
- 일반 보기
- 절 번호 강조 보기
- 집중 읽기 보기
- TTS 음성, 속도, 반복, 자동 스크롤

설정값은 다른 개인 기록과 함께 로컬 또는 로그인 계정 저장소에 보관됩니다.

### 3.11 빠른 이동

빠른 이동 메뉴에서 이어 읽기, 오늘 통독 분량, 홈의 오늘·통독·활동·공부 영역, 성경 리더, 장 선택, 통독 진척도, 강조 구절, 인용 보관함, 본문 검색, 설정, 현재 장 노트를 검색해 바로 열 수 있습니다. 여러 단계의 메뉴를 반복해서 거치지 않고 자주 사용하는 기능으로 이동하기 위한 도구입니다.

### 3.12 계정과 데이터 동기화

이메일과 비밀번호로 회원가입 및 로그인할 수 있습니다. 로그인한 사용자의 통독 기록, 마지막 읽은 위치, 강조, 노트, 인용 구절, 태그, 설정, 통독 플랜은 Supabase 기반 서버 저장소에 계정별로 저장됩니다.

네트워크 또는 서버 저장에 문제가 생기면 기기에 임시 저장하고 상태를 사용자에게 알립니다. 비회원 상태에서 작성한 기기 데이터가 있다면 로그인 후 현재 계정으로 가져올 수 있습니다. 설정에서는 로그아웃, 로컬 데이터 초기화, 회원탈퇴를 직접 실행할 수 있습니다.

### 3.13 한국어 번역 의견 보내기

승인된 한국어 번역이 제공되는 구절에 대해 로그인 사용자가 번역 의견을 보낼 수 있습니다. 문제 유형, 문제가 되는 표현, 더 적절하다고 생각하는 번역 제안, 설명을 함께 작성할 수 있습니다. 이 기능은 번역 품질 개선을 위한 피드백 창구이며, 사용자가 보낸 내용이 즉시 본문에 반영되는 구조는 아닙니다.

### 3.14 QT 커뮤니티와 참여 랭킹

로그인 사용자는 성경 구절을 연결한 QT 글을 작성하고 반응과 댓글로 묵상을 나눌 수 있습니다. 커뮤니티는 `피드`, `내 참여`, `랭킹`, `설정` 탭으로 구분하며, 읽기 완료 기록을 바탕으로 한 참여 현황과 공개 범위를 관리합니다. 개인 성경노트는 자동으로 공개되지 않으며, 사용자가 커뮤니티 작성 화면에서 명시적으로 입력한 본문과 구절 정보만 게시 대상이 됩니다.

## 4. 화면 구성

### 홈

홈은 `오늘`, `통독`, `활동`, `공부` 네 영역으로 구성됩니다.

- **오늘**: 이어 읽기와 오늘의 통독 플랜
- **통독**: 전체·구약·신약 진행률과 오늘 읽은 장
- **활동**: 최근 읽기와 최근 작업 기록
- **공부**: 최근 강조, 인용 구절, 장·절 노트, 태그 요약

### 성경 리더

본문 읽기와 장 이동, 현재 위치 추적, 언어 전환, 읽음 완료, TTS, 노트, 강조, 인용 저장, 복사, 번역 의견 기능이 모여 있는 핵심 화면입니다.

### 통독

전체와 권별 진행률을 확인하고 읽지 않은 다음 장으로 이동합니다. 완료한 장은 필요할 때 읽음 취소할 수 있습니다.

### 강조

저장한 강조 구절을 색상과 성경 권으로 필터링하고, 열기·복사·해제를 실행합니다.

### 인용

주제별 인용 목록을 선택하고, 저장한 구절을 검색·정렬·복사·삭제합니다.

### 검색

언어, 정렬, 구약·신약, 성경 권 조건을 조합해 본문을 찾고 해당 구절을 리더에서 엽니다.

### QT 커뮤니티

웹에서는 왼쪽 사이드 메뉴의 독립 페이지로 열리고, 모바일에서는 오늘 화면의 진입 버튼에서 별도 화면으로 이동합니다. 피드 탐색, 내가 작성하거나 댓글을 남긴 글, 기간별 랭킹, 공개 설정을 내부 탭에서 전환합니다.

### 설정

계정, TTS, 텍스트, 보기 모드를 관리하고 로컬 데이터 초기화나 회원탈퇴 같은 데이터 관리 기능을 실행합니다.

## 5. 대표 사용 흐름

### 매일 통독하기

1. 홈에서 오늘의 통독 분량을 확인합니다.
2. **오늘 분량 열기**를 눌러 첫 장으로 이동합니다.
3. 본문을 읽거나 TTS로 듣습니다.
4. 한 장을 마치면 **읽음 완료**를 누릅니다.
5. 오늘 분량을 모두 마치면 **오늘 완료**로 기록합니다.
6. 다음 실행 때 홈의 이어 읽기에서 마지막 위치를 복원합니다.

### 말씀을 공부하고 기록하기

1. 리더에서 마음에 남는 구절을 선택합니다.
2. 중요, 묵상, 약속, 경고, 예언 중 하나로 강조합니다.
3. 구절 노트에 관찰과 적용점을 기록합니다.
4. 다시 활용할 말씀이라면 인용 보관함에 제목, 태그, 메모와 함께 저장합니다.
5. 나중에 강조 화면이나 인용 보관함에서 검색해 원래 본문으로 돌아갑니다.

### 필요한 구절 다시 찾기

1. 본문 검색에서 한국어 또는 KJV 영어를 선택합니다.
2. 구약·신약이나 특정 성경 권으로 범위를 좁힙니다.
3. 검색 결과에서 원하는 구절을 엽니다.
4. 해당 구절을 복사하거나 강조하고, 노트 또는 인용 목록에 저장합니다.

## 6. 데이터와 개인정보

- 비회원 데이터는 기본적으로 사용 중인 기기의 로컬 저장소에 보관됩니다.
- 로그인 계정 데이터는 인증과 동기화를 위해 Supabase 기반 서버 저장소에 보관됩니다.
- 앱은 읽기 위치, 통독 기록, 강조, 노트, 인용 목록, 태그, 설정, 번역 의견을 기능 제공에 필요한 범위에서 처리합니다.
- 서버 연결에 실패한 경우 로그인 데이터도 기기에 임시 저장될 수 있습니다.
- 사용자는 로컬 데이터 초기화와 회원탈퇴 기능을 직접 사용할 수 있습니다.
- 회원탈퇴 시 현재 계정과 서버에 저장된 통독 기록, 강조, 노트, 인용 구절이 삭제됩니다. 비회원으로 작성한 별도의 기기 데이터는 자동으로 삭제되지 않습니다.
- 사용자 리더노트 데이터를 광고 목적으로 판매하지 않는 정책을 적용합니다.

회원가입 전 또는 설정에서 개인정보 처리방침을 확인할 수 있습니다.

## 7. 콘텐츠와 언어

- 기본 영어 본문은 KJV 계열 데이터를 사용합니다.
- 한국어 본문은 승인되어 공개된 번역 데이터가 있는 구절에서 제공됩니다.
- 한국어 본문이 없는 구절에서는 영어 KJV를 계속 읽을 수 있습니다.
- 본문 화면에는 가능한 경우 번역명과 데이터 출처를 표시합니다.
- 번역 의견 기능은 한국어 번역이 제공되는 구절에서만 사용할 수 있습니다.

## 8. 플랫폼과 기술적 특성

KJV 리더노트는 Next.js 웹앱과 Expo 기반 네이티브 모바일 앱으로 구성되어 있습니다. 모바일 앱은 웹 화면을 WebView로 감싼 형태가 아니라 React Native로 구현된 별도 네이티브 화면이며, 웹과 동일한 성경 API 및 공유 도메인 로직을 사용합니다.

- 웹: 반응형 브라우저 앱
- 모바일: Expo/React Native 기반 앱
- Android 애플리케이션 ID: `com.kjvreader`
- iOS: iPhone 및 iPad 대응 설정 포함
- 화면 방향: 세로 모드
- 테마: 시스템 설정과 앱 설정에 따른 밝은/어두운 화면 지원

이 문서는 코드가 지원하는 플랫폼 범위를 설명하며, 특정 앱 스토어의 현재 공개·심사 상태를 의미하지 않습니다.

## 9. 현재 제공 범위와 제한 사항

- 성경 본문과 검색 결과를 불러오려면 기본적으로 웹 API에 연결할 수 있어야 합니다. 개인 기록의 기기 저장은 지원하지만 전체 본문의 완전한 오프라인 패키지는 현재 범위에 포함되지 않습니다.
- 한국어 본문은 승인·공개된 번역 데이터가 있는 범위에서만 표시됩니다.
- TTS 음성 품질과 사용 가능한 음성 목록은 기기와 운영체제에 따라 달라집니다.
- 계정 동기화와 번역 의견 전송은 Supabase 및 서버 연결이 구성되어 있어야 합니다.
- AI 해설·요약, 의미 기반 검색, 구절 이미지 생성은 현재 핵심 앱 범위에 포함되지 않습니다.
- 앱은 성경 읽기와 개인 공부 기록을 돕는 도구이며, 특정 교단의 해석이나 신학적 판단을 자동으로 제공하지 않습니다.

## 10. 앱의 차별점

KJV 리더노트는 읽기, 통독 관리, 개인 공부 기록을 서로 떨어진 기능으로 취급하지 않습니다. 홈에서 마지막 위치와 오늘 분량을 확인하고, 리더에서 바로 강조·노트·인용 저장을 수행하며, 저장된 기록에서 다시 원문으로 돌아오는 하나의 순환 구조를 제공합니다.

또한 회원가입을 강제하지 않고 먼저 읽기를 시작할 수 있게 하면서, 필요할 때 계정 동기화로 확장할 수 있습니다. 영어 KJV와 제공 가능한 한국어 본문, 통독 플랜, 구절 단위 공부 도구, 기기 TTS를 한 앱 안에서 연결한 것이 핵심 특징입니다.

### 자세한 설명

KJV 리더노트는 KJV 성경 읽기와 통독 기록, 구절 공부를 한곳에서 이어주는 개인 성경앱입니다.

회원가입 없이 바로 성경 읽기를 시작하세요. 마지막으로 읽은 권·장·절을 자동으로 기억하고, 다음 실행에서 이어 읽을 수 있습니다. 1년, 6개월, 90일, 신약 30일 통독 플랜으로 오늘 읽을 분량을 확인하고 전체·구약·신약 통독률을 관리할 수 있습니다.

마음에 남는 구절은 중요, 묵상, 약속, 경고, 예언으로 나누어 강조하세요. 장과 구절별로 묵상 노트를 작성하고, 설교나 글쓰기에 다시 사용할 말씀은 제목·태그·메모와 함께 인용 보관함에 저장할 수 있습니다. 저장한 구절은 검색하고 정렬하거나 성경 위치와 함께 복사할 수 있습니다.

한국어와 KJV 영어 본문 검색, 구약·신약 및 성경 권 필터, 검색 결과에서 원문으로 바로 이동하는 기능도 제공합니다. 기기에 설치된 TTS 음성을 이용하면 현재 장, 선택 구절, 선택 범위 또는 오늘의 통독 분량을 들을 수 있습니다.

비회원 기록은 현재 기기에 저장됩니다. 이메일 계정으로 로그인하면 읽기 위치, 통독 기록, 강조, 노트, 인용 구절과 설정을 계정 기준으로 저장하고 동기화할 수 있으며, 비회원으로 작성한 기기 데이터도 계정으로 가져올 수 있습니다.

주요 기능:

- 성경 66권 권·장·절 탐색
- 마지막 읽은 위치 저장과 이어 읽기
- 전체·구약·신약·권별 통독 진척도
- 1년, 6개월, 90일, 신약 30일 통독 플랜
- 목적별 5색 구절 강조
- 장 노트와 구절 노트
- 제목·태그·메모·목록을 지원하는 인용 보관함
- 한국어·KJV 영어 본문 검색
- 장·구절·선택 범위·오늘 분량 TTS
- 글자 크기, 줄 간격, 테마, 보기 모드 설정
- 비회원 로컬 저장과 로그인 계정 동기화
